#  JOELENT NETWORK
## Sistem Manajemen Pelanggan dan Pembayaran Tagihan WiFi

### Deskripsi Project

**Joelent Network** merupakan aplikasi berbasis console yang dikembangkan menggunakan bahasa pemrograman TypeScript untuk membantu proses pengelolaan data pelanggan dan pembayaran tagihan WiFi.

Aplikasi ini dirancang untuk mempermudah admin dalam melakukan pendataan pelanggan, memperbarui informasi, mencari data, menghapus data pelanggan, serta mengelola pembayaran tagihan dan laporan pendapatan.

Project ini dikembangkan sebagai bagian dari pemenuhan tugas **Ujian Akhir Semester (UAS) mata kuliah Pemrograman Dasar** dengan menerapkan konsep CRUD (Create, Read, Update, Delete), pencarian data, dan pengelolaan array of objects.
